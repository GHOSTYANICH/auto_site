Современный адаптивный промо-лендинг (Landing Page) для сервиса подбора, выкупа с аукционов, доставки и оформления автомобилей из США в Украину «под ключ».

---

## 📌 О проекте

Сайт разработан как высококонверсионная посадочная страница компании **AUTO EXPRESS**. Основная цель ресурса — донести до клиента финансовую выгоду покупки автомобилей с американских страховых аукционов (экономия до 40%), продемонстрировать прозрачность всех этапов доставки и собрать контакты потенциальных клиентов через интерактивные формы.

---

## ✨ Ключевой функционал

- **Hero-секция с оффером**:
  - Быстрый доступ к контактам (телефон, соцсети: Instagram, Telegram, WhatsApp, Facebook).
  - Призыв к действию (CTA) на получение консультации.
- **Информационный блок услуг**:
  - Аналитика выгоды американского рынка перед европейским.
  - Пошаговый пайплайн работы из 6 шагов (подбор $\to$ доставка $\to$ растаможка $\to$ ремонт $\to$ сертификация $\to$ учет).
- **Блок доверия и статистика**:
  - Ключевые показатели компании (650+ доставленных авто, 5 лет опыта, 100% отчетность).
- **Адаптивная карусель кейсов (Fleet Carousel)**:
  - Список пригнанных авто с указанием реальной экономии (Tesla, BMW, Porsche, Audi, Mustang и др.).
  - Автоматическое определение количества видимых карточек в зависимости от ширины экрана (1 / 2 / 3).
  - Автопрокрутка с интервалом 3.5 секунды и интерактивные точки (пагинация).
- **Валидация формы обратной связи**:
  - Проверка имени (не менее 2 символов) и номера телефона (10–15 цифр).
  - Подсветка некорректных полей и вывод подсказок об ошибках.
  - Анимированное подтверждение об успешной отправке без перезагрузки страницы.
- **Toast-уведомления**:
  - Кастомные всплывающие подсказки для ссылок-заглушек (*«Этот раздел скоро появится»*).

## 🛠 Стек технологий

- **HTML5**: семантическая разметка, структурированные секции, доступность (`aria-label`).
- **CSS3**:
  - CSS-переменные (`:root`) для единой цветовой палитры.
  - Сетки на Flexbox и CSS Grid.
  - Адаптивность (Media Queries под мобильные устройства, планшеты и десктоп).
  - CSS Reset для нормализации отображения во всех браузерах.
- **JavaScript (Vanilla JS)**:
  - Написание модулей на чистом JS без сторонних библиотек.
  - Изоляция контекста с помощью IIFE.
  - Реагирование на изменение размеров окна (`window.resize`).
  - DOM-манипуляции, валидация по регулярным выражениям.

## 🚀 Быстрый старт

Проект не требует сборщиков или серверного окружения, запускается прямо в браузере.

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/GHOSTYANICH/auto_site
   ```
2. **Перейдите в папку с проектом**:
   ```bash
   cd project-car
   ```
3. **Откройте файл `index.html`**:
   - Двойным кликом в любом браузере, **или**
   - Через расширение **Live Server** в VS Code для поддержки горячей перезагрузки (Hot Reload).

## 📱 Адаптивность

Интерфейс оптимизирован под различные разрешения экранов:
- 📱 **Mobile** ($\le 600\text{px}$) — одноколоночный вид, компактная навигация, слайдер по 1 авто.
- 💻 **Tablet** ($601\text{px} - 900\text{px}$) — сетка в две колонки, слайдер по 2 авто.
- 🖥 **Desktop** ($> 900\text{px}$) — полноразмерная версия с трёхколоночным слайдером и широкими контейнерами.
